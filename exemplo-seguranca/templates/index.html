Sobre este Projeto

Este é um exemplo didático de sistema de autenticação em Flask que demonstra:

  • ✓ Hash de senhas usando SHA-256 com salt
  • ✓ Armazenamento seguro de credenciais
  • ✓ Gerenciamento de sessões
  • ✓ Proteção de rotas
  • ✓ Validação de entrada
⚠️ Aviso Importante: Este projeto usa SHA-256 para fins educacionais. Em produção, use bcrypt, argon2 ou PBKDF2 que são algoritmos projetados especificamente para hash de senhas.
