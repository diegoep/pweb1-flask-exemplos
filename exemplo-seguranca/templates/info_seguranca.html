Informações de Segurança - Hash SHA-256

🔐 O que é Hash?

Hash é uma função matemática que transforma dados de qualquer tamanho em uma sequência de bytes de tamanho fixo. É um processo unidirecional - você não pode reverter o hash para obter os dados originais.

🔢 SHA-256

SHA-256 (Secure Hash Algorithm 256-bit) é um algoritmo criptográfico que:

  • Gera um hash de 256 bits (64 caracteres hexadecimais)
  • É determinístico - mesma entrada sempre gera a mesma saída
  • Qualquer mudança mínima na entrada muda completamente o hash
  • É computacionalmente inviável reverter o processo

🧂 O que é Salt?

Salt é um valor aleatório único adicionado à senha antes do hash. Benefícios:

  • Previne rainbow table attacks
  • Senhas iguais geram hashes diferentes
  • Aumenta significativamente a segurança
  • Cada usuário tem seu próprio salt único

🔄 Processo de Hash no Sistema

Durante o Registro:

1. Usuário fornece senha: "minhaSenha123" 2. Sistema gera salt aleatório: "a3f9d8c..." 3. Combina: "minhaSenha123a3f9d8c..." 4. Aplica SHA-256: "8f7a3b2..." 5. Armazena apenas o hash e o salt

Durante o Login:

1. Usuário fornece senha: "minhaSenha123" 2. Sistema recupera o salt: "a3f9d8c..." 3. Combina: "minhaSenha123a3f9d8c..." 4. Aplica SHA-256: "8f7a3b2..." 5. Compara com hash armazenado 6. Se idênticos, login aprovado
⚠️ IMPORTANTE - Limitações do SHA-256 para Senhas:

Embora SHA-256 seja seguro, NÃO é ideal para senhas porque:

  • É muito rápido: Facilita ataques de força bruta
  • Hardware especializado: GPUs podem calcular bilhões de hashes por segundo
  • Sem "cost factor": Não pode ser ajustado para ser mais lento

✅ Alternativas Recomendadas para Produção

1. bcrypt

  • Projetado especificamente para senhas
  • Salt automático integrado
  • Cost factor ajustável (pode ser mais lento conforme hardware melhora)
  • Amplamente usado e testado

2. Argon2

  • Vencedor da Password Hashing Competition (2015)
  • Resistente a ataques com GPU e ASIC
  • Configurável em tempo e memória
  • Estado da arte em segurança de senhas

3. PBKDF2

  • Padrão recomendado por NIST
  • Múltiplas iterações de hash
  • Amplamente suportado

📚 Exemplo com bcrypt

from flask_bcrypt import Bcrypt bcrypt = Bcrypt(app) # Hash senha_hash = bcrypt.generate_password_hash('senha123') # Verificar bcrypt.check_password_hash(senha_hash, 'senha123')
