🔍 Como Funciona o Login

Durante o processo de autenticação:

  1. Sua senha é combinada com o salt armazenado
  2. O resultado é processado pelo SHA-256
  3. O hash gerado é comparado com o hash armazenado
  4. Se forem idênticos, o login é bem-sucedido

Importante: A senha original nunca é armazenada ou recuperada!
